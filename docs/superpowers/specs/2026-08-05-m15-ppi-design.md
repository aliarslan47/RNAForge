## 1. Amaç

DEG'ler arasında STRING protein-etkileşim alt-ağı kurup **community (modül) tespiti** ile birlikte-işleyen
fonksiyonel gen gruplarını ortaya çıkarmak. Değişmeyen ilkeler: gate YOK (verdict m06'dan taşınır),
yalancı yok (sembol-join belirsizi atar), sessiz hata yok (eksik STRING → gürültülü), STRING etkileşimleri
**tahmin/kanıt-skorlu** (rapora dürüst not), TDD. Tablo-öncelikli (figür yok — ağ görselleştirme sonraya).

**Neden networkx:** Louvain modülarite optimizasyonu ince; elle yazmak riskli → networkx
(`louvain_communities`, saf-Python, güvenilir) rnaforge-core'a pip ile eklenir (m09/m12/m14 saf-Python çizgisi).

## 2. STRING annotation (`rnaforge/ppi.py`)

- Prep'te indir (gitignore'lu `references/string/<taxid>/`): `protein.links.txt.gz` (**boşlukla ayrılmış**:
  `protein1 protein2 combined_score`) + `protein.info.txt.gz` (**tab**: `#string_protein_id preferred_name …`).
- `parse_string_info(info) -> dict[string_id, symbol]` (preferred_name).
- `parse_string_links(links, min_score) -> list[(p1, p2, score)]` (combined_score ≥ eşik).
- **Join:** `string_id → symbol` (info) + `symbol → locus_tag` (GFF `parse_gff_go` üçüncü dönüşü,
  `_symbol_to_locus` tam+benzersiz) → `string_id → locus_tag`.

## 3. Alt-ağ + community (`rnaforge/ppi.py`, networkx)

- `build_deg_network(deg_ids, edges, string2lt) -> nx.Graph`: DEG locus_tag'leri düğüm; STRING kenarının
  iki ucu da DEG ise `weight=score/1000` kenarı ekle. `detect_communities(G, seed=42) -> list[list[locus_tag]]`
  (`louvain_communities`, deterministik seed, ağırlıklı).
- `summarize_communities(communities, gene_symbol, de) -> list[dict]`: modül başına üye sembol, boyut,
  n_up/n_down (log2FC), dominant yön. Boyuta göre sıralı; küçük (<`min_community_size`, ör. 3) modüller özet dışı.

## 4. Modül (`rnaforge/modules/m15_ppi.py`) + CLI

`run_ppi(config, metadata_path, run_dir, force=False)`: ön koşul **m06**; `ppi.taxid` + STRING dosyaları
gerekli (yoksa gürültülü hata). **Gate YOK.** Çıktı `ppi/communities.tsv` (community_id, size, n_up, n_down,
dominant, genes) + `statistics/ppi_statistics.json` (n_deg, n_deg_in_network, n_edges, n_communities, min_score).
Yeni `rnaforge ppi` subcommand. Zincir m06 tabanlı.

## 5. Rapor (`report_html.py`)

Yeni **"Protein Etkileşim Modülleri (STRING)"** bölümü (Operon'dan sonra, Methods'tan önce): en büyük
modüller tablosu (modül, boyut, yön, üye genler) + "N DEG ağda, M modül" özeti. **Dürüst not:** STRING
etkileşimleri kanıt-skorludur, eşik combined_score ≥ {min_score}. Yöntem/Kaynak: STRING (Szklarczyk ve ark.
2023) + Louvain (Blondel ve ark. 2008). Tolerant. verdict değişmez.

## 6. Config & prep

`KNOWN_TOP_LEVEL_KEYS`'e. **networkx** rnaforge-core'a (pip; `envs/rnaforge-core.yml` güncel). STRING dosyaları
