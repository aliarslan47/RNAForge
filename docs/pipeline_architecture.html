Organizma kararı ÜÇ kola ayrılır: prokaryot (sol), ökaryot (sağ) ve metatranskriptom (merkez — rRNA temizleme + gen-kataloğu niceleme + Kraken2/Bracken taksonomi); üçü de m06 diferansiyel ifadede birleşir. m06 merkez hub'dır; tanı modülleri (m16/m17/m18) nicelemeden sonra koşar. RNAForge Pipeline DAG

The real run() dependency graph. Linear spine m00→m01→m03→m04→m05→m06; read QC (m02) is a branch off validation. The organism decision splits into THREE arms: prokaryote (left), eukaryote (right) and metatranscriptome (center — rRNA depletion + gene-catalog quantification + Kraken2/Bracken taxonomy); all three rejoin at m06 differential expression. m06 is the central hub; diagnostics (m16/m17/m18) run after quantification. Read type (short/long) is an orthogonal, tool-level axis.
