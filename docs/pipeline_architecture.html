RNAForge Pipeline DAG

The real run() dependency graph. Linear spine m00→m01→m03→m04→m05→m06; read QC (m02) is a branch off validation. Quantification and counting (m04–m05) split into prokaryote / eukaryote by organism and rejoin at m06 differential expression. m06 is the central hub: figures, GO/KEGG/GSEA/semantic, PPI and prokaryote-only AMR/operon branch from it. Diagnostic modules (m16/m17/m18) run after quantification. Read type (short/long) is an orthogonal, tool-level axis.
